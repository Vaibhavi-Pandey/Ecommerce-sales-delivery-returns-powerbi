# E-Commerce Sales, Delivery & Returns Performance Dashboard

## Overview
An interactive 5-page Power BI dashboard analyzing e-commerce sales, profitability, product returns, and delivery/customer operations across multiple Indian states to identify what drives or erodes profitability despite revenue growth.

## Repository Contents
- `Ecommerce_Sales_Analysis_Dashboard_PowerBi.pbix` – Power BI report file with data model, DAX measures, and interactive pages.
- `Ecommerce_Sales_Analysis_Dashboard_PowerBi.pdf` – Exported report/project overview.

## Tools & Skills Demonstrated
- Power BI Desktop: Data modeling, interactive report design, slicers, conditional formatting.
- Power Query: Automated data cleaning and preparation.
- DAX: Measures for Total Revenue, Total Profit, Total Orders, Returned Orders, Return Rate %, Average Rating, and Average Delivery Days.

## Dashboard Pages
-  Executive Overview: High-level KPIs covering Total Revenue, Total Profit, Total Orders, Return Rate %, and Average Customer Rating.
-  Sales Analysis:  Revenue by region, product category, customer segment, monthly trend, and top 10 products.
-  Returns Analysis:  Returned vs. non-returned orders, return reasons, and returns broken down by category, state, and product.
-  Profitability:  Profit by category and state, Discount vs. Profit scatter analysis, and top/bottom performing products.
-  Customer & Operations:  Customer ratings by category, payment method mix, delivery days by region, delivery status, and sales channel performance.

## Key Findings
- Flagged a  25% return rate  concentrated in  Sports  and  Home , with  damaged goods  standing out as a primary return reason.
- Enabled dynamic slicing across regions, categories, payment methods, and delivery/return metrics to pinpoint operational and profitability bottlenecks.
